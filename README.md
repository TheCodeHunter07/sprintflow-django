# SprintFlow

SprintFlow is a project and task management backend inspired by tools like Jira and Trello. It is being built to learn professional backend software engineering practices using Django and Django REST Framework.

## Tech Stack

- Python 3.12
- Django 5.2 LTS
- Django REST Framework
- PostgreSQL
- Docker (planned)
- Git & GitHub

## Project Status

🚧 Under Development

Current Sprint:
- ✅ Sprint 0 – Project Foundation
- ⏳ Sprint 1 – Project Architecture & User Module

## Getting Started

1. Clone the repository
2. Create a virtual environment
3. Install dependencies

```bash
pip install -r backend/requirements.txt
```

4. Create a `backend/.env` file from `backend/.env.example`

5. Run migrations

```bash
python manage.py migrate
```

6. Start the development server

```bash
python manage.py runserver
```
